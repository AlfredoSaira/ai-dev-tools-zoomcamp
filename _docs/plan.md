# Weekly Team Feedback Tool – MVP Scope

## Product goal
Help project teams collect honest weekly feedback, turn it into a focused retrospective, and leave the meeting with documented decisions and action items.

## Core workflow

### 1. Create a feedback cycle
A facilitator creates a weekly feedback cycle for a project and invites the team.
The facilitator is usually the project owner, but the role can be assigned to another team member.

### 2. Collect feedback
Each team member submits their weekly feedback before the retrospective meeting.
Feedback is short, honest, and categorized (Green, Yellow, Red).

### 3. Run retrospective
The facilitator reviews the collected feedback with the team.
The group discusses highlights, blockers, and risks.

### 4. Document decisions
The facilitator records agreed‑upon actions and decisions in the plan.
This ensures accountability and continuity across weeks.

### 5. Track progress
Each new week adds a new cycle.
The plan accumulates feedback history, decisions, and outcomes.

## MVP features
- Simple CLI to create and manage weekly feedback cycles
- Store feedback in Markdown files
- Generate a weekly report for the team
- Keep history of past weeks

## Non‑goals
- No complex UI
- No advanced analytics
- No integrations with external tools (Slack, Jira, etc.)
